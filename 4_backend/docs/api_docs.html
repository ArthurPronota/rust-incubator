GraphQL Friends API Documentation

API for managing users and their friends with authentication support.

Быстрый старт

GraphQL Endpoint: POST http://127.0.0.1:8080/graphql
Playground: GET http://localhost:3000/graphql

Authentication

For secure requests, you must add a JWT token to the POST request.

Authorization: Bearer <your-token>

Available operations

Mutation User registration


mutation {
  register(inp: { name: "Arthur", password: "Pass10" }) {
    token
    user {
      id
      name
    }
  }
}

Mutation Authentication


mutation {
  login(inp: { name: "Arthur", password: "Pass10" }) {
    token
    user {
      id
      name
    }
  }
}

Query Getting information about a user with friends


query {
  userplus(jwt: "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUz ... 6x6eY79uL8D6sYvud7Rry4vrubM_1tpJM96Dl056DIE") {
    id
    name
    friends {
      id
      name
      friends {
        id
        name
      }
    }
  }
}

Mutation Adding a friend


mutation {
  addfriend(inp: { friendid: 1, jwt: "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUz ... 6x6eY79uL8D6sYvud7Rry4vrubM_1tpJM96Dl056DIE" }) {
    friend {
      id
      name
    }
  }
}

Mutation Removing a friend


mutation {
  delfriend(inp: { friendid: 2, jwt: "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUz ... 6x6eY79uL8D6sYvud7Rry4vrubM_1tpJM96Dl056DIE" }) {
    friend {
      id
      name
    }
  }
}

Data models

User


{
  id: Int!         # ID User
  name: String!    # Unique username
  friends: [User]! # Список друзей
}

Query optimization

The API uses DataLoader to optimize database queries. Nested friend queries are grouped and executed by a single SQL query.

Limiting the depth of queries

The maximum depth of a GraphQL query is limited to 10 levels to prevent DoS attacks.

Safety

  • Passwords are hashed using Argon2id
  • JWT tokens have a 24-hour expiration date.
  • All requests for friends' data require authentication.
  • SQL injection protection via parameterized sqlx queries

Starting the server

          
# Setting environment variables
# Edit the .env file

# Starting the server
cargo run --bin server

# Запуск тестов
cargo test

Launching the client

              
# Register a new user
cargo run --bin client -- user-register Arthur Pass10

# Login
cargo run --bin client -- login Arthur Pass10

# Add a friend
cargo run --bin client -- add-friend 3 eyJ0eXAiOiJKV1QiLCJhbGciOiJIUz ... 6x6eY79uL8D6sYvud7Rry4vrubM_1tpJM96Dl056DIE

# Remove friend
cargo run --bin client -- del-friend 3 eyJ0eXAiOiJKV1QiLCJhbGciOiJIUz ... 6x6eY79uL8D6sYvud7Rry4vrubM_1tpJM96Dl056DIE

# Show friends and their friends
cargo run --bin client -- show-friends eyJ0eXAiOiJKV1QiLCJhbGciOiJIUz ... 6x6eY79uL8D6sYvud7Rry4vrubM_1tpJM96Dl056DIE
